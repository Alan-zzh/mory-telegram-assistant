## Mory 小助理 · 业务愿景简述

### 核心定位

**不是普通群管机器人**——是带真人设的 **运营型商业 AI 转化机器人**。

### 商业愿景

通过 Telegram 群组生态，以「Mory 小助理」人设（清冷傲娇 + 网感拉满的真人女孩）与用户建立自然对话关系，在信任感中温和引导商业转化，实现「从聊天到下单」的完整闭环。

### 产品方向（当前已实现 + 长期演进）

| 维度 | 当前状态（v5.28.0） | 长期愿景 |
|------|---------------------|----------|
| **人设对话** | 10 维商业目标 + 25 mode 路由 + 4 模板 | 更丰富的自适应人设切换（场景感知 × 用户画像 × 情绪识别） |
| **商业转化** | 3 档产品矩阵 + 54 个自动任务 + 购物车挽回 | 全自动增长引擎（AB 实验 → 归因 → 质量评估 → 自动调优闭环） |
| **运营观察** | Dashboard 156 API + 8 类设置面板 | AI 自动运营建议（非人工看板，让 Bot 自己优化自己） |
| **消息分发** | 34 个 P 级别拦截点 | 更细粒度的场景感知路由，减少 LLM 调用浪费 |
| **群管能力** | 88 个模块 + 108 张表 | 多 Bot 联邦 + 跨群协作 + 自动策略推荐 |
| **AI 自主性** | 固定 API + 4 活跃模型池 | 多模型路自适应 + 预算感知路由 + 离线备用 |

### 长期原则

- **业务红线不可触碰**：绝不死机 / 绝不自曝 AI / 绝不直白营销 / 绝不重复话术 / 绝不跨界产品 / 绝不 Bot 内收款
- **数据驱动**：每个改动可归因、可度量、可回滚
- **渐进增强**：优先最小可行改动，迭代验证后再铺开
- **运营先行**：所有技术选择服务于"提高转化率"这个核心业务目标
