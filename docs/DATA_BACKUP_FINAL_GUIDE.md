# 📦 Mory小助理 - 数据备份完整指南

## 🎯 你的问题，完美解决

你担心的"VPS出问题数据全丢、机器人记忆又要重新训练"的问题，我已经设计了一个**双重保险系统**：

### 🔐 **第一层保险：本地自动备份（主力）**
**每次更新VPS时，自动把数据下载到你电脑上**

✅ **优点**：
- VPS完全炸了也没事，本地有完整副本
- 完全自动化，不用你操心
- 每次更新都备份，数据永远最新
- 恢复简单，一键搞定

### 📱 **第二层保险：Telegram私聊备份（辅助）**
**需要时发私聊指令，机器人把数据发给你**

✅ **优点**：
- 随时随地用手机就能获取
- 按需备份，不占本地空间
- 格式灵活（zip、统计、CSV）

## 🛠️ 我为你创建了什么

### 1. **一键工具（双击就能用）**
- `backup_vps_data.bat` - 手动完整备份
- `restore_from_backup.bat` - 从备份恢复VPS
- `vps_one_click_update.bat` - 更新时自动备份

### 2. **自动化系统**
- **每次快速更新**（update模式）：自动备份数据库+配置
- **每次完整部署**（full模式）：自动备份数据库+配置
- **保留策略**：自动保留最近7天备份，清理旧的

### 3. **完整恢复能力**
- 恢复前**自动备份当前状态**（防止恢复出错）
- 恢复后**自动验证数据完整性**
- 支持**选择历史备份点**恢复

### 4. **备份内容**
- `mory.db` - 最重要的数据库（用户数据、记忆、配置）
- `config.json` - API密钥等敏感配置
- 数据库信息统计（每个表有多少记录）

## 🚨 最坏情况应对

### 场景：VPS彻底打不开了
1. **你有本地完整备份**（在`backups/latest/`）
2. **租个新VPS**，安装基础环境
3. **上传项目代码**到新VPS
4. **恢复备份数据**：
   ```bash
   # 把 backups/latest/mory.db 上传到新VPS
   # 把 backups/latest/config.json 上传到新VPS
   # 启动bot
   ```
5. **机器人记忆完整恢复**，无需重新训练

### 场景：误删了重要数据
1. **从历史备份恢复**（有多个时间点）
2. **选择删除前的备份**
3. **恢复** → 数据回来了
