# 塔罗小阿卡纳（56 张）策展规范模板

> 版本：v1.0（2026-08-23）| 依据：三路专家团评审 + 外部调研（Mary K. Greer 宫廷牌理论、花色元素体系）
> 用途：`mystic_content.py` 小牌上量立项前的内容策展验收标准；不达标不上线。

## 一、数据结构

沿用 `_TAROT_CARDS` 元组结构，扩展进 `data/tarot_cards_full.json`（立项时定加载方式：模块内 `lru_cache` 懒加载，**禁止**接入 KeywordManager 单例——纯函数模块引入全局态会破坏测试可控性）：

```json
{
  "权杖Ace": {"num": "A", "suit": "权杖", "element": "火",
              "upright": ["w1", "w2", "w3", "w4", "w5"],
              "reversed": ["r1", "r2", "r3", "r4", "r5"]}
}
```

## 二、策展铁律（每条都必须过审）

1. **宫廷牌 = 人物特质，不是事件牌**。侍从=消息与起步、骑士=推进与速度、王后=内在整合、国王=外化掌控；逆位转向该能量的阴影面，不是反义词。
2. **花色元素一致**：权杖=火(行动)、圣杯=水(情感)、宝剑=风(思维/沟通)、星币=土(物质/务实)；关键词不得跨花色漂移。
3. **数字牌循数序脉络**：Ace(种子)→2(权衡)→3(初成)→4(稳固)→5(冲突)→6(调和)→7(评估)→8(精进)→9(将成)→10(完结)，同数字跨花色共享结构。
4. **宝剑不全写负面**：宝剑亦有澄清、真相、决断义。
5. **逆位 = 受阻/内化/延迟式**，禁止机械取反。
6. **星币禁写"财运到"类断言**：写资源/务实/身体力行（撞项目金钱回避红线）。
7. **首位关键词冻结**：`upright[0]` 被 insight「今日主轴」引用，定稿后不可重排。
8. **跨花色去重校对轮**：全部 56×2×3 起步词完成后做一轮同义词扫描，防多花色重复"成长/停滞"。
