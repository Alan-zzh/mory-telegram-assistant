# 播报图片卡视觉哲学 · 晨昏同律（Dusk-Daylight Continuum）

> 版本 v1.0（2026-08-06）｜适用范围：`core/broadcast_image_card.py` 全部卡型（问候/黄历/塔罗/易经/新闻/定点播报）。
> 本文件是图片卡视觉决策的唯一基准；后续改配色、字号、纹理前先对照本文，禁止随手调参。

## 一、总纲：光变，律不变

一张卡片从清晨到深夜都在同一套秩序里呼吸。白天主题以纸为底、以墨为骨；
夜晚主题以夜为底、以灯为字。**主题的切换只是光的迁移，不是版式的重画**——
每一个色键在任何主题下都必须保证"底与字"的对比是预先校准过的，
绝不允许出现"浅色字落在浅色底"这类未经推演的组合。每一处对比度都应当
像被反复称量过一样精确：正文与所在底面的明度差是这套系统的第一铁律。

## 二、空间与留白：呼吸优先

卡片是竖屏上的一个安静房间。外边距、区块间距、行距全部服从同一节奏：
内容块之间留出完整的呼吸段，装饰永远退到内容之后。云纹、描边、菱形分隔
只允许出现在**没有背景图的素底卡片**上；一旦启用摄影/绘画背景，
装饰必须让位——背景自己就是纹理，再叠纹样就是噪音。
这种克制必须显得是深思熟虑的取舍，而不是疏漏。

## 三、色彩与材质：底面决定字的颜色

- 浅色主题（morning/afternoon）：暖纸底 + 墨字，区块用同族浅色块承托；
- 深色主题（evening/night）：夜色底 + **深色区块底面** + 近白字。
  深色主题下区块必须沉下去（深蓝墨底），让文字像灯一样浮上来；
  忌栏、塔罗牌面、六爻盒随主题整体换材质，不允许某个角落停留在白天。
- 强调色（墨绿/朱砂/暖金）在深色主题下使用提亮变体，
  保持色相不变、明度上抬——色如其人，只是换了一盏灯。
- 调用方自带的浅色标签底（如时辰吉凶的浅绿/浅朱底）上，
  文字永远用深色，与主题无关——**底是浅的，字就必须是深的**。

## 四、字号与层级：手机上的可读性是底线

800px 宽的卡片在手机上会被二次压缩，任何小于 16px 的正文级文字都视为缺陷：
标签、键值、牌面关键词一律 ≥16px；播报时间等次要信息 ≥17px；
正文 ≥20px；标题独占 52px 的碑刻级尺度。层级靠"尺度 × 色阶"双通道表达，
不靠堆装饰。每个字号的选定都应像是为最差的压缩条件反复试过。

## 五、执行标准：看不见的打磨

投影、圆角、描边的参数以"几乎察觉但取下就空"为准——
投影轻、描边细、圆角统一。所有改动不得破坏现有降级链
（图片卡 → Rich Message → HTML），不得引入模型调用，
不得让单张卡的绘制逻辑分叉出第二套版式。
最终成品应当让人觉得：这张卡是被一笔一笔校出来的，而不是拼出来的。
