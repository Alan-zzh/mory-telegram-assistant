## ❓ 常见问题

### 机器人不回复？
```bash
bash start.sh log     # 看日志
# 常见原因：
# - TOKEN错误 → 重新从@BotFather获取
# - API_KEY错误 → 检查通义千问控制台
# - 模型额度用完 → 自动切换，等几秒就好
```

### 数据库损坏？
```bash
# 自动备份在 backup/ 目录，直接恢复最近的：
bash start.sh restore
# 或者手动恢复：
cp backup/mory_backup_最近的文件.db mory.db
bash start.sh restart
```

### 机器人回复很慢？
```bash
# 查看当前模型和状态
bash start.sh log100
# 如果是模型限流，会自动切换，不需要操作
```

### 更新后启动失败？
```bash
# 查看错误日志
bash start.sh log100
# 一键回滚到更新前
bash start.sh restore
```

## ⚙️ 技术架构

- **语言：** Python 3.8+
- **Telegram库：** pyTelegramBotAPI（长轮询模式，不支持消息删除事件监听）
- **AI引擎：** 通义千问（DashScope API，兼容OpenAI格式）
- **数据库：** SQLite（单文件，线程安全，互斥锁，12张表）
- **消息分发：** 优先级队列 P0→P10（新人→黑名单→管理员→AI）
- **后台任务：** daemon线程，60秒轮询
- **模型轮换：** 14个模型按到期日排序，额度用尽自动切换下一个
- **备份策略：** 每小时备份，保留7天（168份）+ 更新前自动备份
